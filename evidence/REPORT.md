## 设计与页面

首页采用「导航 → 介绍与像素猫 → 最近文章 → 主题 → 页脚」；桌面长文采用正文与右侧目录，手机目录置于正文前、默认折叠。暖纸白与暖黑主题共享间距、字号与交互规则。已实现首页、归档、主题索引与详情、文章、条件开放的关于页、404、搜索、RSS 和 sitemap。

正文为结构化内容块；使用系统字体、原创 SVG 小猫与原生浏览器功能，没有应用依赖。小猫 SVG 加全站浏览器脚本 gzip 合计 2,390 字节，远低于 50KB 目标。

## 本轮补完

- 修复连续复制导致反馈文字无法恢复：执行与反馈期间禁用同一按钮，统一恢复原文。
- 正文标题锚点避开页面保留 ID，`main`、`query` 等标题不会覆盖页面控件。
- 阅读时长只统计可读文字，不再把 JSON 字段名计入；支持非中文语言的字母与数字单词。
- 修正主题详情的标题层级，补足导航、文章标题等入口的触控尺寸与手机辅助字号。
- 缩短小猫的移动距离，避免窄屏预留区域裁切猫本体。
- 手机目录默认折叠，消除脚本加载后收起目录造成的正文位移；桌面开启 JS 时展开，无 JS 可手动展开。
- 添加明确标注的原创排版示意图，覆盖实际图片资源、懒加载、图注和原图链接。
- 搜索弹层 Escape 不再连带关闭底层手机菜单，焦点按预期恢复。
